## 一、数值平衡设计总览

本文档定义了《剑来》横版格斗游戏的完整数值系统，包括12个角色的基础属性、技能配置、战斗公式、关卡难度以及AI行为参数。数值设计遵循"差异化定位、动态平衡、策略深度"三大原则，确保每个角色都有独特的战斗风格，同时保证整体游戏体验的公平性和趣味性。

### 1.1 核心数值框架

游戏采用「剑气」作为核心资源循环系统，所有技能都需要消耗剑气，而普通攻击和特定条件可以恢复剑气。这种设计鼓励玩家在进攻和防守之间做出策略选择。基础伤害值（DV）作为伤害计算的核心参数，通过各种系数修正最终形成实际伤害输出。角色的属性成长曲线采用非线性设计，随着关卡推进，基础属性的边际收益递减，确保不同阶段的战斗节奏保持紧凑。

### 1.2 数值单位与范围

| 数值类型 | 范围 | 说明 |
|---------|------|------|
| 生命值（HP） | 1000 - 5000 | 根据角色定位浮动 |
| 攻击力（ATK） | 80 - 200 | 伤害计算基础值 |
| 防御力（DEF） | 20 - 80 | 减伤计算基础值 |
| 速度（SPD） | 1.0 - 3.0 | 攻击间隔系数 |
| 剑气值（SP） | 0 - 100 | 技能释放资源 |
| 技能伤害系数 | 0.5 - 3.0 | 相对于攻击力的倍率 |
| 冷却时间（CD） | 3 - 30秒 | 技能循环周期 |

## 二、角色基础属性配置

### 2.1 阵营定位与数值分布

四大阵营在基础属性上具有明显的风格倾向性，这种倾向性决定了每个角色在战斗中的定位和打法。剑仙阵营以高攻击力和高速度著称，但防御力相对较低，典型的玻璃大炮型角色。儒道阵营各项属性较为均衡，更强调技能的特殊效果和策略运用。佛道阵营拥有最高的生命值和防御力，但攻击速度较慢，适合持久战。妖族阵营在攻击力和生命值之间取得平衡，部分角色具有爆发性伤害能力。

## 三、技能数值配置

### 3.1 技能设计原则

每个角色的技能组遵循「1控+1伤+1辅+1必杀」的设计框架，确保技能组合具备完整的战斗功能。技能伤害系数（相对于角色攻击力）在0.8到2.5之间浮动，根据技能的功能性和冷却时间进行平衡调整。冷却时间与技能强度呈正相关，但通过剑气消耗、资源回收等机制进行整体循环平衡。

## 四、战斗平衡公式

### 4.1 伤害计算公式

伤害计算遵循多层系数相乘的原则，确保各种伤害修正效果能够合理叠加。基础伤害由技能伤害系数乘以角色攻击力得到，然后依次应用防御减免、属性克制、暴击修正、连击加成等系数。

```
最终伤害 = 基础伤害 × 防御修正 × 属性修正 × 暴击修正 × 连击修正 × 特殊修正

基础伤害 = 技能伤害系数 × 角色攻击力

防御修正 = 1 - (敌方防御力 / (敌方防御力 + 常数K))
其中 K = 600（常数，确保防御收益递减）
```

**防御修正示例**：当敌方防御力为50时，防御修正 = 1 - 50/(50+600) = 1 - 0.077 = 0.923，即受到7.7%的伤害减免。当敌方防御力为100时，防御修正 = 1 - 100/700 = 0.857，即受到14.3%的伤害减免。

### 4.2 格挡减伤公式

格挡系统为玩家提供主动防御手段，成功格挡可以大幅降低受到的伤害。格挡判定发生在伤害计算之前，成功的格挡会应用额外的格挡减伤系数。

```
格挡判定：格挡率 = (格挡属性 / (格挡属性 + 常数M)) × 技能类型修正
其中 M = 500，技能类型修正：普通攻击=1.0，轻技能=0.8，重技能=0.5，终极技能=0.2

格挡减伤 = 格挡成功时应用
最终伤害 = 基础伤害 × (1 - 格挡减伤率) × 防御修正 × ...

格挡减伤率 = 基础格挡减伤 × 格挡时机修正
基础格挡减伤 = 0.6（60%减伤）
格挡时机修正：完美格挡（伤害判定前0.1秒内）= 1.2，普通格挡 = 1.0
```

**完美格挡示例**：完美格挡时格挡减伤率为 0.6 × 1.2 = 0.72，即格挡成功后受到的基础伤害减免达到72%，再乘以防御修正，最终减伤效果约为85%。

### 4.3 连击加成公式

连击系统鼓励玩家保持连续攻击，攻击间隔越短，连击加成越高。连击加成通过「连击数」和「连击时间窗口」两个维度进行计算。

```
连击加成 = 基础加成 × 时间衰减 × 连击数加成

基础加成 = 1.0 + (连击数 × 0.05)
连击数加成：每第10次连击额外+10%加成

时间衰减：当两击之间间隔超过2秒时，连击数清零
         间隔1-2秒：连击数减半
         间隔0.5-1秒：连击数保留80%
         间隔0.5秒以内：连击数完全保留
```

**连击加成示例**：在0.3秒内完成第15次连击，基础加成 = 1.0 + 15×0.05 = 1.75，第10次额外加成触发，总连击加成为1.85。最终伤害 = 基础伤害 × 1.85。

### 4.4 技能循环DPS平衡原则

技能循环DPS是衡量角色战斗效率的核心指标，设计时遵循以下平衡原则：

**同定位角色DPS相近原则**：相同定位（如「高爆发」）的角色，在理想输出环境下的技能循环DPS相差不超过10%。通过调整技能冷却时间、技能伤害系数和剑气消耗来实现平衡。

**资源循环平衡原则**：高伤害技能必然伴随高冷却和高消耗，确保整体资源循环的可持续性。角色的剑气恢复速度（每秒恢复量）与技能平均消耗保持平衡，使玩家能够在战斗中持续使用技能而非依赖普通攻击。

**技能循环DPS计算公式**：

```
技能循环DPS = Σ(技能伤害 × 技能释放频率) / 时间周期

技能释放频率 = 1 / 技能冷却时间（考虑剑气消耗后的实际释放频率）

时间周期 = 各个技能冷却时间的最小公倍数（通常取60秒或120秒作为标准周期）
```

### 4.5 属性克制系统

四大阵营之间存在属性克制关系，合理的属性克制可以在战斗中获得显著优势。

| 攻击阵营 | 被克制阵营 | 克制效果 |
|---------|-----------|----------|
| 剑仙 | 妖族 | 伤害+15%，技能冷却-10% |
| 儒道 | 剑仙 | 封印剑仙技能效果概率+20% |
| 佛道 | 儒道 | 儒道增益效果抵抗率+30% |
| 妖族 | 佛道 | 对佛道角色伤害+20%，攻击速度+15% |
| 其他 | 无 | 无克制加成，但也不被克制 |

**克制判定规则**：克制效果在伤害计算中的属性修正阶段应用，克制系数为1.15或1.20。被克制方不产生惩罚性减伤，仅攻击方获得加成。

## 六、AI难度参数配置

### 6.1 AI难度分级概述

游戏提供四级AI难度，从简单到地仙，满足不同水平玩家的需求。AI行为参数涵盖攻击频率、技能使用、资源管理、闪避反应、策略多样性等多个维度。难度升级通过提高AI的反应速度、技能释放时机和策略复杂度来实现，而非简单地增加敌人属性。

### 6.2 四级AI核心参数

#### 简单难度（入门级）

**适用场景**：新手教程、前期关卡、练习模式

**攻击行为参数**：
| 参数名称 | 参数值 | 说明 |
|---------|--------|------|
| 攻击频率 | 0.3次/秒 | 每3-4秒攻击一次 |
| 技能释放率 | 20% | 只有20%的机会释放技能 |
| 技能命中率 | 40% | 技能释放后命中率较低 |
