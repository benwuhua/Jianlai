**创建日期**: 2026-01-29
**目标平台**: HarmonyOS (Mate X5折叠屏)
**游戏类型**: 传统横版格斗游戏

## 1. 第二阶段概述

### 1.1 目标

在第一阶段（核心战斗）基础上，实现：
- 多角色选择系统（10+个角色，四大阵营）
- 完整技能系统（3个特殊技能+1个必杀技）
- 陈平安双模式（剑修/武夫）
- 难度分级AI（简单/普通/困难/地仙）
- 角色选择界面和难度选择界面

### 1.2 用户流程

```
启动游戏 → 主菜单 → 角色选择 → 难度选择 → 战斗 → 结算 → 返回
```

## 2. 角色选择系统

### 2.1 设计方案

**用户体验：**
- 传统格斗游戏方式：战斗前在单独界面选择角色
- 显示10+个可选角色
- 每个角色显示：头像、名称、阵营、基础属性

**技术实现：**
- 创建 `CharacterSelect.ets` 页面，使用Grid布局
- 创建 `CharacterManager.ets` 管理角色数据加载
- 角色配置使用JSON文件存放在 `resources/rawfile/characters/`

### 2.2 四大阵营角色

**剑仙阵营**（3-4个）：
- 陈平安（双模式：剑修/武夫）
- 宁姚（高爆发，飞剑攻击）
- 阿良（全能型，剑术大师）
- 左右（剑气长城大剑仙）

**儒道阵营**（2-3个）：
- 齐静春（辅助型，阵法加持）
- 秀萍（控制型，墨家机关）
- 文庙大祭酒（策略型，状态加持）

**佛道阵营**（2-3个）：
- 佛国大佛（坦克型，高防御回血）
- 菩萨泥塑（法术型，金身不坏）
- 渡僧（持续型，念经恢复）

**妖族阵营**（3-4个）：
- 王座大妖（高攻击，变身机制）
- 飞剑妖族（敏捷型，速度极快）
- 蛮荒妖族（力量型，范围伤害）
- 智慧妖族（法师型，妖术攻击）

## 3. 技能系统设计

### 3.1 技能架构

每个角色有4个技能位：
- **技能1-3（特殊技能）**：冷却时间10-15秒，消耗少量剑气
- **必杀技（大招）**：冷却时间30-60秒，需要满剑气槽释放

**剑气系统：**
- 攻击和受击积攒剑气
- 技能消耗剑气（10-30点）
- 必杀技需要100点剑气

### 3.2 陈平安 - 双模式角色

**剑修模式（默认）：**
- 普通攻击：剑斩（中距离）
- 技能1：猛虎硬爬山（突进+伤害）
- 技能2：剑气斩（远程剑气）
- 技能3：春风化雨（回血）
- 必杀：剑气长城（全屏剑气）

**武夫模式（按V键切换，冷却10秒）：**
- 普通攻击：拳法（短距离，高伤害）
- 技能1：搬山（击飞+砸地）
- 技能2：倒海（范围攻击）
- 技能3：观海（防御姿态，减伤80%）
- 必杀：十二重楼（拳法连击，巨额伤害）

**武夫模式特点：**
- 防御+50%，血量+30%
- 攻击距离缩短，但伤害+30%
- 切换有2秒动画和特效（拳风爆发）
- 持续时间不限，可手动切换回剑修模式

### 3.3 其他角色技能示例

**宁姚**：
- 技能1：飞剑连刺（连续多段攻击）
- 技能2：剑意护体（临时提升防御）
- 技能3：瞬步（快速移动）
- 必杀：宁剑一式（巨额单体伤害）

**齐静春**：
- 技能1：教化（减速敌人）
- 技能2：书院阵法（持续恢复）
- 技能3：圣人威压（范围眩晕）
- 必杀：天地画卷（全屏控制效果）

## 4. AI系统设计

### 4.1 难度分级

**简单（小白）**：
- 随机移动和攻击
- 不会主动使用技能
- 攻击间隔长（3-5秒）
- 不会格挡或闪避

**普通（练气士）**：
- 有一定逻辑：靠近时攻击，远离时等待
- 偶尔使用技能（20%概率）
- 会简单的格挡（30%概率）
- 攻击间隔2-3秒

**困难（金丹）**：
- 主动使用技能（50%概率）
- 会连招（攻击→技能→必杀）
- 会格挡和闪避（60%概率）
- 会预判玩家行为
- 攻击间隔1-2秒

**地仙（极难）**：
- 精通技能使用（80%概率）
- 完美的格挡和闪避（80%概率）
- 会使用取消技（技能取消后摇）
- 会预判并反击
- 攻击间隔<1秒

### 4.2 AI技术实现

- 使用状态机：IDLE、MOVE、ATTACK、DEFEND
- 根据难度设置AI参数（反应速度、格挡率、技能使用率）
- 决策考虑：距离、玩家状态、自身冷却、能量槽
- 优先级：保命（低血量时格挡/闪避）→ 攻击 → 待机

    └── AIBehavior.ets            # 新增：AI行为配置

### 5.2 数据模型

**角色配置：**
```typescript
interface CharacterConfig {
  id: string;
  name: string;
  faction: 'swordsman' | 'confucian' | 'buddhist' | 'demon';
  baseStats: CharacterStats;
  skills: SkillConfig[];
  ultimate: SkillConfig;
  aiBehavior?: AIBehavior;
}

interface ModeConfig {
  default: CharacterConfig;
  alternate: CharacterConfig;
  switchCooldown: number;
}
```

**技能配置：**
```typescript
interface SkillConfig {
  id: string;
  name: string;
  type: 'active' | 'passive' | 'ultimate';
  cooldown: number;  // 毫秒
  kiCost: number;    // 剑气消耗
  damage: number;
  range: number;
  effect?: string;   // 特效名称
}
```
