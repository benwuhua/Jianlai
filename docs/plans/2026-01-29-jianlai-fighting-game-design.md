# 《剑来》格斗游戏设计文档

**创建日期**: 2026-01-29
**目标平台**: HarmonyOS (Mate X5折叠屏)
**游戏类型**: 传统横版格斗游戏

---

## 1. 项目概述

基于小说《剑来》世界观开发的横版格斗游戏，支持Mate X5单屏和展开双屏模式。玩家可选择不同阵营的角色（各州剑仙、儒释道三教修士、妖族等），通过闯关模式体验《剑来》中的经典战役。

### 1.1 核心特性

- **传统横版格斗**: 类似拳皇、街霸的1v1对战，注重连招和格挡
- **多阵营可选**: 剑仙、儒道、佛道、妖族四大阵营，各有独特战斗风格
- **折叠屏适配**: 单屏紧凑布局，展开模式显示扩展信息面板
- **单人闯关**: 剧情模式和闯关模式，挑战各路剑仙和妖族

---

## 2. 整体架构设计

### 2.1 应用结构

- **单页应用模式**: 主界面是格斗场景，通过状态管理切换界面
- **组件化设计**: 角色选择器、战斗场景、控制器、UI面板等独立组件
- **Ability生命周期**: 管理屏幕折叠/展开状态，动态调整布局

### 2.2 核心模块

**战斗系统模块** (`GameEngine.ets`)
- 输入检测、碰撞判定、伤害计算
- 角色状态管理（移动、攻击、受击、死亡）
- 连击系统和格挡机制

**角色系统模块** (`CharacterSystem.ets`)
- 角色数据结构（属性、技能、动画）
- 多阵营角色库管理
- 角色创建和状态同步

**屏幕适配模块** (`FoldableScreenAdapter.ets`)
- 监听设备折叠状态变化
- 单屏/展开模式布局切换
- 扩展信息面板管理

**关卡系统模块** (`LevelSystem.ets`)
- 闯关进度管理
- 敌人配置和难度递增

## 3. 角色系统与战斗机制

### 3.1 角色数据结构

每个角色包含：
- **基础属性**: 生命值、攻击力、防御力、速度
- **剑气值**: 能量槽，攻击和受击积累，满值释放必杀技
- **技能配置**:
  - 普通攻击（3-5段连击）
  - 特殊技能（2-3个）
  - 必杀技（1个）
- **阵营特性**:
  - 剑仙阵营: 高攻击，飞剑技能，机动性强
  - 儒道阵营: 控制技能多，防御加成，阵法加持
  - 佛道阵营: 生存能力强，回血技能，减伤护盾
  - 妖族阵营: 高爆发，变身机制，狂暴状态

### 3.2 战斗机制

**操作方式**:
- 虚拟摇杆控制移动
- 攻击按钮（轻击/重击）
- 技能按钮（2-3个）
- 格挡/闪现按钮

**核心系统**:
- **连击系统**: 普通攻击衔接3-5段，最后一段击飞
- **剑气系统**: 积攒剑气释放必杀技（"齐静春的天地画卷"、"陈平安的拳头"等）
- **格挡机制**: 完美格挡反弹伤害并反击
- **受击硬直**: 被击中后短暂无法行动

**AI设计**:
- 初期关卡: 简单AI，随机攻击
- 中期关卡: 智能AI，会连招和格挡
- Boss关卡: 高级AI，使用必杀技，二阶段变身

## 4. 折叠屏适配与UI布局

### 4.1 屏幕适配策略

**单屏模式（折叠状态）**:
- 战斗区域占满屏幕
- 血条悬浮在顶部（半透明）
- 操作按钮固定在底部
- 不显示额外信息面板

**展开模式（双屏状态）**:
- 左侧/上方: 主战斗区域（约65%）
- 右侧/下方: 扩展信息面板（约35%）
  - 详细血条和剑气槽（带动画）
  - 技能冷却倒计时
  - 连击数统计
  - 战斗日志
  - 实时帧率和延迟

### 4.2 响应式布局实现

```typescript
@State isFolded: boolean = true;
@State currentLayout: LayoutConfig = LayoutConfig.FOLDED;

onFoldStateChange(isFolded: boolean) {
  this.isFolded = isFolded;
  this.currentLayout = isFolded ? LayoutConfig.FOLDED : LayoutConfig.EXPANDED;
}
```

### 4.3 UI组件层级

1. **底层**: 背景场景（骊珠洞天、剑气长城、落魄山等）
2. **中层**: 角色渲染（Canvas或Image序列帧）
3. **上层**: UI控件（血条、按钮、技能图标、扩展面板）
4. **特效层**: 技能特效、打击特效、必杀技全屏动画

### 4.4 性能优化

- 单屏和展开使用不同渲染分辨率
- 展开模式启用更高清特效
- 对象池管理特效粒子

## 5. 关卡系统

### 5.1 剧情模式

- **第1-3章**: 骊珠洞天篇（陈平安初学武艺）
- **第4-6章**: 剑气长城篇（对抗妖族）
- **第7-9章**: 书简湖篇（水遁修行）
- **第10章+**: 彩蟾、桐叶宗、旧天庭遗迹

### 5.2 闯关模式

- 每关3-5个敌人，最后是Boss
- 难度递增: 简单 → 普通 → 困难 → 地仙 → 飞升
- 通关奖励: 解锁新角色、技能升级材料、皮肤

### 5.3 Boss设计

- 各州最强剑仙（阿良、左右等）
- 妖族大妖
- 二阶段机制（血量低于50%时变身）

## 6. 技术实现

### 6.1 渲染引擎

- **Canvas 2D**: 绘制游戏画面（性能好，兼容性强）
- **XComponent + 原生渲染**: 更高性能选项
- **角色动画**: Lottie JSON或序列帧图片

### 6.2 物理系统

- 简单的AABB碰撞检测
- 重力、跳跃、冲刺等基础物理
- 轻量级实现，不使用复杂物理引擎

### 6.3 数据持久化

- **Preferences API**: 存储进度（角色解锁、关卡进度）
- **关卡配置**: `resources/rawfile/levels/` (JSON格式)
- **角色数据**: `resources/rawfile/characters/`

### 6.4 音效系统

- **背景音乐**: `@ohos.multimedia.audio`
- **音效**: 打击音效、技能音效（预加载到内存池）
- **BGM切换**: 不同关卡不同音乐

### 6.5 性能监控

- 目标帧率: 60fps
- 展开模式适当降低特效保持流畅
- 使用 `PerformanceAnalysisKit` 监控

## 8. 开发优先级

### 第一阶段：核心战斗
1. 搭建基础游戏框架和主循环
2. 实现单个角色的基础移动和攻击
3. 简单的碰撞检测和伤害计算
4. 基础UI（血条、攻击按钮）

### 第二阶段：系统完善
1. 完善角色系统（多角色、技能、连击）
2. 实现AI对手
3. 添加音效和特效
4. 角色选择界面

### 第三阶段：折叠屏适配
1. 监听折叠状态
2. 实现单屏/展开两套布局
3. 扩展信息面板

### 第四阶段：内容填充
1. 设计多个关卡
2. 添加更多角色
3. 剧情模式和闯关模式
4. 数据持久化

### 第五阶段：优化打磨
1. 性能优化
2. 视觉打磨
3. 测试和bug修复
